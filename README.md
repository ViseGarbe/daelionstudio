# Daelion Studio

Sito statico per Daelion Studio.

La struttura è multipagina: `index.html` è la home, mentre `approccio.html`, `progetti.html`, `metodo.html`, `parliamone.html` e `privacy.html` sono le pagine dedicate.

`privacy.html` contiene Privacy Policy, Cookie Policy e Note legali. Il sito non include banner cookie, sistemi di consenso, analytics o strumenti di profilazione.
